# Reference

## Public API

| item | what it is |
|---|---|
| `LexerEngine` | the trait a lexer implements |
| `LexerRequest` | source text + language + position, as handed to an engine |
| `Lexer` | handle over an engine; `new` / `with_options` construct it |

## Crate

| crate | role |
|---|---|
| `hnl-engine-lex` | abstraction — contract only |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # no test suite here — covered by consumers
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
